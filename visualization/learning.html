1. 分子动力学模拟与 LAMMPS 基础

经典分子动力学（Molecular Dynamics, MD）把原子或粗粒化粒子视为遵循经典力学的质点。给定粒子间势能后，程序计算每个粒子的力，并用很小的时间步反复积分牛顿方程，从而得到位置和速度随时间变化的轨迹。

\[m_i\frac{\mathrm{d}^2\mathbf{r}_i}{\mathrm{d}t^2}=\mathbf{F}_i=-\nabla_i U(\mathbf{r}_1,\mathbf{r}_2,\ldots)\]
  1. 定义模型：选择粒子、相互作用势、模拟盒和边界条件。
  2. 建立初态：生成坐标，指定温度对应的初速度，避免粒子严重重叠。
  3. 平衡体系：用恒温器或恒压器，使温度、密度等达到目标状态。
  4. 生产模拟：固定实验协议，连续输出热力学量和粒子轨迹。
  5. 统计分析：由轨迹计算 MSD、扩散系数、分布函数及不确定度。

常见系综

系综保持或控制的量本实验中的用途
NVE粒子数、体积、总能量检查无恒温器时的能量守恒
NVT粒子数、体积、温度固定盒体积后测量轨迹和 MSD
NPT粒子数、压强、温度让盒体积调整到目标压强对应的平衡密度

LAMMPS 是 Large-scale Atomic/Molecular Massively Parallel Simulator 的缩写。它是开源的经典分子动力学引擎：读取文本输入脚本，建立粒子体系、计算作用力、积分运动方程并输出轨迹。LAMMPS 负责可靠地执行模拟；研究问题、参数选择、平衡判据和数据解释仍由使用者负责。

先记住：一条轨迹只是一次带有限粒子数、有限时间和特定随机初态的数值实验。模拟“成功运行”不等于结论已经收敛。

建议先读

  • LAMMPS 官方概览：LAMMPS 能模拟什么，以及它如何积分粒子运动。
  • LAMMPS 输入脚本结构：初始化、体系定义、设置、运行四个基本部分。
  • A. Rahman, “Correlations in the Motion of Atoms in Liquid Argon,” Physical Review 136, A405–A411 (1964), DOI: 10.1103/PhysRev.136.A405。这是用 Lennard–Jones 势研究液氩动力学和自扩散的经典早期工作。

2. 本实验的 Lennard–Jones 模型

本实验使用单组分、三维 Lennard–Jones（LJ）粒子。任意两个粒子之间只通过距离 r 决定相互作用：

\[U(r)=4\varepsilon\left[\left(\frac{\sigma}{r}\right)^{12}-\left(\frac{\sigma}{r}\right)^6\right]\]
  • \(\sigma\)：长度尺度；当 \(r=\sigma\) 时势能为零。
  • \(\varepsilon\)：能量尺度；势阱最低点为 \(-\varepsilon\)。
  • \(r^{-12}\)：描述短距离强排斥。
  • \(r^{-6}\)：描述较长距离的吸引。
  • \(r_{\min}=2^{1/6}\sigma\)：势能最低、作用力为零的位置。

LAMMPS 中使用 pair_style lj/cut 2.5，即在 \(r_c=2.5\sigma\) 处截断；pair_modify shift yes 将势能整体平移，使 \(U(r_c)=0\)。截断模型和无限程 LJ 势并不完全相同，比较文献时必须确认其势函数、截断半径和尾修正。

LJ 约化单位

在 units lj 中取 \(\sigma=\varepsilon=m=k_{\mathrm B}=1\)。模拟输出没有预设的米、秒或帕；需要选择一种真实物质的 \(\sigma,\varepsilon,m\) 才能换算。

物理量约化量恢复实际单位
长度\(r^*=\frac{r}{\sigma}\)\(r=r^*\sigma\)
温度\(T^*=\frac{k_{\mathrm B}T}{\varepsilon}\)\(T=\frac{T^*\varepsilon}{k_{\mathrm B}}\)
时间\(t^*=\frac{t}{\sigma\sqrt{m/\varepsilon}}\)\(t=t^*\sigma\sqrt{\frac{m}{\varepsilon}}\)
压强\(P^*=\frac{P\sigma^3}{\varepsilon}\)\(P=\frac{P^*\varepsilon}{\sigma^3}\)
速度\(v^*=\frac{v}{\sqrt{\varepsilon/m}}\)\(v=v^*\sqrt{\frac{\varepsilon}{m}}\)
扩散系数\(D^*=\frac{D}{\sigma\sqrt{\varepsilon/m}}\)\(D=D^*\sigma\sqrt{\frac{\varepsilon}{m}}\)

氩参数换算示例

若取 \(\sigma=3.405\,\text{Å}\)、\(\varepsilon/k_{\mathrm B}=119.8\,\mathrm K\)、\(m=39.948\,\mathrm u\)，则时间单位约为 \(2.156\,\mathrm{ps}\)，扩散系数单位约为 \(5.377\times10^{-8}\,\mathrm{m^2/s}\)。因此 \(T^*=2\) 对应约 \(239.6\,\mathrm K\)，\(100t^*\) 对应约 \(215.6\,\mathrm{ps}\)；\(P^*=0.30\) 算例的 \(D^*=1.662\) 对应约 \(8.94\times10^{-8}\,\mathrm{m^2/s}\)。

建议任务：从原始论文或可信数据手册查找另一种稀有气体的 σ、ε/kB 和原子质量，独立完成时间、压强、速度与扩散系数的 SI 换算，并说明这种映射的局限。

3. LAMMPS 如何生成本项目的数据

本项目把“用于计算扩散系数的数据”和“用于课堂三维展示的数据”分开生成。两者先进行相同的周期边界 NPT 平衡，但生产阶段的边界条件不同。

输入文件与驱动脚本

文件作用
lammps/in.lj_diffusion_pressure周期边界长轨迹：NPT 平衡后固定体积做 0–500 t* 的 NVT，用于 MSD 和 D–P 分析。
lammps/in.lj_diffusion_pressure_reflective_preview反射墙短轨迹：NPT 平衡后切换六面反射墙，做 0–100 t* 的 NVT，用于动画。
scripts/run_pressure_diffusion.py依次运行五个目标压强的长轨迹。
scripts/run_pressure_diffusion_preview.py依次运行五个目标压强的反射墙预览轨迹。
scripts/analyze_pressure_diffusion.py由 thermo.csv 和 msd.csv 拟合扩散系数与压强关系。

输入脚本中的关键命令

units lj                    # 使用 LJ 约化单位
pair_style lj/cut 2.5      # 12-6 LJ 势，截断半径 2.5σ
fix ... npt                # 调整盒体积，达到目标 T* 和 P*
fix ... nvt                # 固定体积并控制温度
compute ... msd            # 计算均方位移
dump ... custom            # 输出坐标、未折返坐标和速度
fix ... wall/reflect       # 预览轨迹中的六面反射墙

一次压力算例的运行顺序

  1. 按照初始密度生成 500 个 FCC 格点粒子，并从 Maxwell 分布抽取初速度。
  2. 运行 30,000 步 NPT，使体积和密度适应目标压强。
  3. 冻结平衡后的盒体积，并根据粒子的 x 坐标赋予左右示踪标签。
  4. 长轨迹保持周期边界运行 100,000 步；预览轨迹切换反射墙运行 20,000 步。
  5. 输出热力学量、MSD、轨迹和最终构型，再由独立脚本生成汇总表和图。
