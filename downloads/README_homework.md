# 六选一作业数据说明

只需使用自己所选题目的文件夹，不需要分析其他五题，也不要求运行模拟。

| 目录 | 问题 | 主要文件 |
|---|---|---|
| Q1_speed_distribution | 温度与速率分布 | 三个温度的速率样本 CSV 和 states.csv |
| Q2_pressure | 同温度下压强与扩散 | 五个工况的 thermo.csv 与 msd.csv |
| Q3_boundaries | 周期边界与反射墙 | periodic 与 reflecting 的 MSD 和状态量 |
| Q4_temperature_diffusion | 固定密度下温度与扩散 | 三个温度的 MSD 和状态量 |
| Q5_system_size | 体系大小与重复波动 | diffusion_replicates.csv 及每个大小一条代表 MSD |
| Q6_velocity_correlation | 速度自相关与扩散 | 三个重复的自相关 CSV 和对应 MSD |

## 单位与字段

全部使用 Lennard-Jones 约化单位，参考质量、sigma、epsilon 和 k_B 为 1，积分时间步为 0.005。不要把 time 当成动画播放的秒数。

- thermo.csv 的 time 是生产段时间；temp、pressure、density、volume 分别为瞬时温度、标量压强、质量密度和盒体积。粒子质量为 1，因此质量密度与数密度数值相同。
- pe_per_atom、ke_per_atom、etotal_per_atom 是明确除以粒子数后的能量，不是全体系总量。基础任务不要求使用这些列。
- msd.csv 的 msd 是三维总均方位移，扣除整体质心漂移，周期体系包含跨界位移。三维扩散区间的斜率除以 6 得到扩散系数。
- 速率文件的 vx、vy、vz 为速度分量，speed 是它们的矢量模。每个温度提供一条代表轨迹的五个快照，共 10240 个粒子样本；相邻或不同粒子样本不等于同等数量的独立模拟。
- states.csv 提供实测平均状态。比较压强时使用实测平均压强，不直接复制目标压强。
- 题五的 D 按各条生产段 20%–90% 时间窗口、带截距线性回归得到。每个 N 有五个独立种子，可以画所有重复点和组均值；不要求必须外推无限大体系。
- 题六的 lag_time 为滞后时间，vacf 为三维速度点积相关，已对 512 个示踪粒子与多个时间起点平均；有效起点数随滞后时间变化。速度每 0.02 采样一次，原始高频记录长 100，提供的相关最大滞后为 20。D 等于相关时间积分的三分之一。归一化曲线可用于比较衰减，计算 D 时应积分原始 vacf，而不是直接积分归一化值。

## 哪些数据来自不同实验

题一与题四固定数密度 0.1，粒子数 2048，温度为 1.5、2.0、3.0。题二固定温度 2.0、粒子数 2048，先进行 NPT 调整体积再进行固定体积 NVT；题五单独固定温度 1.5、数密度 0.8，比较 256、864、2048、6912 个粒子。这些不同条件的结果不能混在一起解释成单一变量的效应。

题三两套轨迹是在各自边界下调整后开始记录，不能拼接。反射墙长期 MSD 受盒尺寸限制，不能把其长期斜率解释为体相扩散系数。

## 学生包与教师参考

每个题目文件夹内的 `input.lmp` 均为服务器实际使用的原始 LAMMPS 输入文件，内容未改写。只提供一个工况供参考，不代表该题全部数据。

| 题目 | 示例工况 ID | 参数与准备方式 |
|---|---|---|
| Q1_speed_distribution | temperature_t15_r1 | N=2048，T=1.5，数密度 0.1，周期边界，NVT |
| Q2_pressure | pressure_p030_r1 | N=2048，T=2.0，目标 P=0.30；NPT 准备后固定体积 NVT |
| Q3_boundaries | boundary_reflect_r1 | N=2048，T=2.0，数密度 0.1；周期准备后切换六面反射墙 |
| Q4_temperature_diffusion | temperature_t15_r1 | N=2048，T=1.5，数密度 0.1，周期边界，NVT；与题一示例相同 |
| Q5_system_size | size_n0864_r1 | N=864，T=1.5，数密度 0.8，周期边界，NVT，第一次独立重复 |
| Q6_velocity_correlation | temperature_t20_r1 | N=2048，T=2.0，数密度 0.1，周期边界，NVT，含高频速度输出 |

自愿运行时，先安装支持这些命令的 LAMMPS（原计算版本为 stable_30Sep2026），将所选 `input.lmp` 复制到**新的空目录**，在该目录执行 `lmp -in input.lmp`。不同安装的可执行文件名可能不同。输入文件自行创建粒子与初速度，不依赖其他初始构型，也不要求 GPU；运行时会生成或覆盖当前目录下的 `thermo.csv`、`msd.csv`、`final.data` 等文件。不要在提供的作业数据目录中直接运行。

原文件保留完整模拟长度：准备 30000 步、调整 10000 步，再生产采样 100000 步（题五为 200000 步）。CPU 运行可能需要较长时间；仅检查能否运行时可自行缩短 `run` 步数，但短测试不能替代作业数据。题六的高频速度文件约百 MB，缩短采样段时需同时调整后续两段 `run`。

输入输出是原始模拟记录。作业 CSV 还经过选取快照、字段整理及删除分段 `run` 交界处完全相同的重复时间行等处理，因此重新运行的输出不必与作业 CSV 逐字节相同。题六的 `vacf_single_origin.csv` 来自 LAMMPS 单一起点的 `compute vacf`；作业提供的相关函数则由 `dense_velocity.lammpstrj` 对 512 个粒子、多时间起点后处理得到，两者不能直接当作同一个统计量。速率样本和题五的逐次扩散系数也需从原始输出进一步整理或拟合。参考输入不包含教师答案与分析程序。

本包提供完成任选题所需的轻量 CSV，不附六题的完整答案。每题另附一个工况的原始输入文件；教师保存全部独立重复、日志与高频原始速度轨迹；希望自拟问题的同学可以申请使用。全部正式数据在同一张 RTX 5090 上用 LAMMPS stable_30Sep2026 双精度计算。
