# 六选一作业数据说明

只需使用自己所选题目的文件夹，不需要分析其他五题，也不要求运行模拟。

| 目录 | 问题 | 主要文件 |
|---|---|---|
| Q1_speed_distribution | 温度与速率分布 | 三个温度的速率样本 CSV 和 states.csv |
| Q2_pressure | 同温度下压强与扩散 | 五个工况的 thermo.csv 与 msd.csv |
| Q3_boundaries | 周期边界与反射墙 | periodic 与 reflecting 的 MSD 和状态量 |
| Q4_temperature_diffusion | 固定密度下温度与扩散 | 三个温度的 MSD 和状态量 |
| Q5_system_size | 体系大小与重复波动 | diffusion_replicates.csv 及每个大小一条代表 MSD |
| Q6_velocity_correlation | 速度自相关与扩散 | 三个重复的自相关 CSV 和对应 MSD |

## 单位与字段

全部使用 Lennard-Jones 约化单位，参考质量、sigma、epsilon 和 k_B 为 1，积分时间步为 0.005。不要把 time 当成动画播放的秒数。

- thermo.csv 的 time 是生产段时间；temp、pressure、density、volume 分别为瞬时温度、标量压强、质量密度和盒体积。粒子质量为 1，因此质量密度与数密度数值相同。
- pe_per_atom、ke_per_atom、etotal_per_atom 是明确除以粒子数后的能量，不是全体系总量。基础任务不要求使用这些列。
- msd.csv 的 msd 是三维总均方位移，扣除整体质心漂移，周期体系包含跨界位移。三维扩散区间的斜率除以 6 得到扩散系数。
- 速率文件的 vx、vy、vz 为速度分量，speed 是它们的矢量模。每个温度提供一条代表轨迹的五个快照，共 10240 个粒子样本；相邻或不同粒子样本不等于同等数量的独立模拟。
- states.csv 提供实测平均状态。比较压强时使用实测平均压强，不直接复制目标压强。
- 题五的 D 按各条生产段 20%–90% 时间窗口、带截距线性回归得到。每个 N 有五个独立种子，可以画所有重复点和组均值；不要求必须外推无限大体系。
- 题六的 lag_time 为滞后时间，vacf 为三维速度点积相关，已对 512 个示踪粒子与多个时间起点平均；有效起点数随滞后时间变化。速度每 0.02 采样一次，原始高频记录长 100，提供的相关最大滞后为 20。D 等于相关时间积分的三分之一。归一化曲线可用于比较衰减，计算 D 时应积分原始 vacf，而不是直接积分归一化值。

## 哪些数据来自不同实验

题一与题四固定数密度 0.1，粒子数 2048，温度为 1.5、2.0、3.0。题二固定温度 2.0、粒子数 2048，先进行 NPT 调整体积再进行固定体积 NVT；题五单独固定温度 1.5、数密度 0.8，比较 256、864、2048、6912 个粒子。这些不同条件的结果不能混在一起解释成单一变量的效应。

题三两套轨迹是在各自边界下调整后开始记录，不能拼接。反射墙长期 MSD 受盒尺寸限制，不能把其长期斜率解释为体相扩散系数。
